# Projet-Carte

# Présentation

Cuphead Interactive Map est une carte interactive dédiée à l'univers du jeu vidéo Cuphead.

L'objectif du projet est de permettre aux utilisateurs d'explorer la carte, de consulter les différents points d'intérêt et, après connexion, de personnaliser leur expérience en ajoutant des points, en commentant les éléments présents et en suivant leur progression.
